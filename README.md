# week4_Cloud_Edge_simulation
# Cloud-Edge Task Scheduling Simulation

## Overview
This project simulates task allocation in a cloud-edge computing environment.

## Techniques Used
- Breadth First Search (BFS)
- Greedy Algorithm

## Features
- Task scheduling
- Load balancing
- Graph visualization using NetworkX

## How to Run
1. Install dependencies:
   pip install networkx matplotlib

2. Run:
   week2.py for week 2 deliverable
   week4.py for week 4 deliverable
   week6.py for week 6 deliverable
   simulator.py for the complete cloud base simulator
