# Cloud-Edge Task Scheduling Simulation

## Overview
This project simulates task allocation in a cloud-edge computing environment.

## Techniques Used
- Breadth First Search (BFS)
- Greedy Algorithm

## Features
- Task scheduling
- Load balancing
- Graph visualization using NetworkX

## How to Run
1. Install dependencies:
   pip install networkx matplotlib

2. Run:
   python graph.py
